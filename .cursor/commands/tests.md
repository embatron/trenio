# Tests

Run the unit tests and the Playwright page checks, then recommend what to change.

## Do this now

1. Read `.cursor/skills/trenio-tests/SKILL.md`.
2. Run `npm test`.
3. Run `npm run test:e2e`. If Chromium is missing, install it with `npx playwright install chromium` and run the e2e command again.
4. Exercise the changed page in the browser when the suite does not already cover that flow.
5. Answer in Russian with the skill's recommendation shape: result, what to change, and the next test to add.
