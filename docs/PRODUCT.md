# Trenio.by — продукт и каталог

Рабочий документ для MVP, frontend-прототипа и SEO-структуры каталога.

> Доменная модель аккаунтов, сущностей и onboarding — в [ACCOUNT_MODEL.md](./ACCOUNT_MODEL.md).
> Реализованные frontend-маршруты — в [README.md](./README.md).

## 1. Позиционирование и MVP

Trenio.by помогает найти тренера, клуб или секцию по городу, виду спорта, формату занятий и контактам.

**Не обещаем:** проверку квалификации, документов, лицензий, безопасности занятий или результат тренировок. Пользователь самостоятельно принимает решение о взаимодействии.

### Входит в MVP

- публичный каталог тренеров и клубов;
- спортивная таксономия (категории и виды спорта);
- городские SEO-страницы;
- профили тренеров и клубов;
- контакты и быстрые CTA;
- SMS/Telegram-подтверждение контактов (техническое подтверждение канала);
- Filament-админка для контента;
- аналитика просмотров и контактных кликов;
- PWA-ready frontend.

### Не входит в MVP

- бронирование, онлайн-оплата, комиссии и подписки;
- проверка документов и квалификации;
- полноценный кабинет клуба, чат, календарь, CRM;
- отзывы после занятий как обязательный механизм.

## 2. Поисковые сценарии

Пользователь ищет связку: **кто** (тренер / клуб / секция) + **где** (город) + **направление** + **для кого** + **формат** + **контакт**.

| Сценарий                       | Пример                                              |
| ------------------------------ | --------------------------------------------------- |
| Тренер по виду спорта в городе | тренер по боксу Минск → `/trainers/minsk/boks`      |
| Клуб по виду спорта в городе   | клуб кикбоксинга Минск → `/clubs/minsk/kikboksing`  |
| Широкая категория в городе     | единоборства Минск → `/trainers/minsk/edinoborstva` |
| Поиск по имени                 | `/search`                                           |
| Поиск по формату               | онлайн, группы, дети/взрослые — фильтры каталога    |

**UX-принцип карточки:** за 3–5 секунд понятно — кто это, где, чем занимается, подходит ли и как связаться.

## 4. Спортивная таксономия

Два уровня: **SportCategory** (широкий раздел) и **Sport** (конкретный вид спорта или устойчивое направление). Используются для URL, фильтров, SEO и перелинковки.

> Цели занятий, аудитория и форматы — отдельные признаки, не смешивать с категориями.
>
> На главной странице выводим только **SportCategory** (первый уровень). Конкретные виды спорта остаются для фильтров, SEO-страниц и вложенной навигации.
>
> В коде таксономия хранится в `src/lib/catalog/sport-taxonomy.ts`: у каждого дочернего направления есть стабильный `slug`, родительская категория и URL вида `/categories/{parentSlug}/{childSlug}` (например, `/categories/edinoborstva/tajskij-boks`). Список всех категорий — `/categories`. Под hero на странице родительской и дочерней категории — плитки-ссылки на все направления раздела (активное — фирменный `--primary`, белый текст).

## 6. SEO

### Индексируемые URL

- `/trainers/{city}`, `/trainers/{city}/{category|sport}`
- `/clubs/{city}`, `/clubs/{city}/{category|sport}`
- `/sports/{slug}`, `/categories/{slug}`, `/cities/{slug}`

### Правила индексации

- Индексируются только страницы с реальным контентом или подготовленным SEO-текстом.
- Пустые страницы — `noindex`, не в sitemap.
- Query-фильтры не создают отдельные индексируемые URL.
- У каждой важной страницы — canonical; старые slug → redirect на canonical.

> Пример: `/trainers/minsk/boks` индексируется при наличии опубликованных тренеров; `/trainers/gomel/padel` — `noindex`, если профилей нет.

## 7. Публичные профили и контакты

Структура полей сущностей — в [ACCOUNT_MODEL.md](./ACCOUNT_MODEL.md). Здесь — UX-правила отображения.

### Профиль тренера (публично)

Имя, фото или placeholder, город, виды спорта, описание, формат, аудитория, цена (если указана), контакты, пояснение что Trenio.by — каталог.

### Профиль клуба / филиала (публично)

Название, город, адрес, направления, описание, контакты, связанные тренеры. Тип представления: nominal, basic, extended, featured.

### Подтверждение контактов

Подтверждение = владелец контролирует канал связи. **Не** означает проверку квалификации или личности.

Статусы: `not_verified`, `pending`, `verified`, `failed`, `expired`.

| Можно                                         | Нельзя                                              |
| --------------------------------------------- | --------------------------------------------------- |
| «Телефон подтверждён», «Telegram подтверждён» | «Проверенный тренер», «Верифицированный специалист» |

## 8. Empty states

| Состояние                   | Сообщение                                                                      |
| --------------------------- | ------------------------------------------------------------------------------ |
| Поиск без результатов       | По вашему запросу ничего не найдено. Попробуйте изменить город или вид спорта. |
| Город без тренеров          | В этом городе пока нет опубликованных тренеров по выбранному направлению.      |
| Категория без тренеров      | Раздел создан, но профили пока не добавлены.                                   |
| Клуб без связанных тренеров | Тренеры клуба пока не привязаны.                                               |
| Тренер без фото             | Нейтральный placeholder                                                        |
| Тренер без цены             | «Цена не указана»                                                              |
| Контакт не подтверждён      | Badge подтверждения не показывается                                            |
| SEO-страница noindex        | Доступна пользователю, закрыта от индексации                                   |

## 9. Админка (Filament)

На MVP админка важнее полноценных личных кабинетов.

- города, категории, виды спорта, alias-ы;
- тренеры и клубы, привязки к видам спорта и между собой;
- контакты, публикация / скрытие / блокировка;
- поиск профилей без фото, контактов или города;
- управление index/noindex для SEO-страниц.

## 10. Сценарии использования

### Поиск тренера

1. Главная → выбор города и вида спорта (например, Минск + Бокс).
2. `/trainers/minsk/boks` → фильтры (дети/взрослые, формат, онлайн/офлайн).
3. Профиль тренера → «Показать телефон» / «Написать в Telegram» → лог контактного клика.

### Поиск клуба

1. `/clubs/minsk/edinoborstva` → карточка клуба.
2. Адрес, направления, контакты, связанные тренеры → переход на сайт / Telegram / звонок.

**Итог:** SEO-каталог с чистой таксономией, городскими страницами, профилями и измеримой конверсией через контактные клики.
